# 合成生物学科学媒体转译

本 Skill 关注“科学主张在画面中如何被正确表示”。它可以规划媒体，也可以拼接用户已有片段；两种任务要分别说明完成状态。

## 建立镜头契约

先收集受众、用途、时长、画幅、已有素材和发布渠道。每个重要镜头绑定四项信息：

| 层次 | 内容 |
|---|---|
| 传播意图 | 观众在这一镜头后应理解什么？ |
| 允许主张 | 哪一句话已有来源或用户数据支持？ |
| 视觉语义 | 画面是实拍、数据图、机制示意还是AI生成示意？ |
| 制作约束 | 素材、时长、字幕、授权和待确认事项是什么？ |

来源不足的主张改成待核验项。概念动画、细胞示意和AI生成素材必须明确标记其性质，不能冒充显微影像、本队结果或专家背书。具体赛事事实按相应年份官方资料核验。

## 规划任务

使用 [分镜模板](assets/storyboard-template.md) 输出镜头契约、旁白、屏幕文字、来源编号和素材类型，并用 [素材清单](assets/materials-checklist.md) 跟踪版权、隐私和可用状态。镜头数量由叙事决定，不套用固定段数。

成本较高或视觉歧义较大的内容可以先制作一个代表性镜头，用来验证风格和科学表达；这只是可选的风险控制方式。使用外部生成服务前核对当前能力、价格与授权，未经用户授权不上传未公开资料、不购买额度、不发布内容。

## 本地拼接任务

已有视频片段时，读取 [操作指南](docs/操作指南.md) 和 [清单格式](references/manifest.md)，再使用 `scripts/compose_video.py`：

1. 将输出尺寸、帧率、片段顺序、裁剪范围和可选字幕写入JSON清单。
2. 先运行 `--dry-run` 查看解析后的计划；预览不创建输出。
3. 执行合成并检查生成报告。程序拒绝覆盖已有输出或与输入冲突的目标。
4. 实际播放成片，复核镜头顺序、比例、字幕、音频和科学标记。

工具会丢弃所有原片音轨，生成静音轨或使用一条替换配乐；字幕为外置 SRT。保留现场声、多轨混音、字幕烧录、云端素材生成和自动发布不属于本工具，必须换用已验证的编辑能力并如实说明。

## 完成状态

只使用下面的状态，避免把文案或自动报告冒充成片：

- **媒体简报完成**：只有受众、主张和制作边界。
- **分镜完成**：已有逐镜文本与素材需求，素材可能尚未制作。
- **本地合成完成，待播放复核**：已经产生MP4，但尚未完整观看。
- **已人工复核**：记录实际查看的文件、重点和遗留问题。

向 OpenMAIC 等课堂平台交接时提供允许主张、视觉类型、来源和禁止误标项；平台生成的画面仍需复核。团队介绍见 [介绍](docs/介绍.md)，教学练习见 [教学指南](docs/教学指南.md)。
