# 合成清单 v1

清单是 UTF-8 JSON 对象，相对路径基于清单文件的目录。仅接受本地文件，不处理远程 URL。v1 的字段名拼错会报错，避免默默忽略用户设置。

| 字段 | 类型 | 默认 / 限制 |
| --- | --- | --- |
| `schema_version` | 整数 | 必填，值为 1 |
| `output` | 字符串 | 必填，新建 `.mp4` 路径 |
| `width`, `height` | 整数 | 默认 1280、720；偶数，16—7680 |
| `fps` | 整数 | 默认 25；1—60 |
| `clips` | 数组 | 必填，1—100 个片段 |
| `soundtrack` | 字符串 | 可选；本地替换配乐，循环至全片结束 |
| `soundtrack_volume` | 数值 | 默认 0.25；0—1，线性音量比例 |

每个 `clips` 条目：

| 字段 | 类型 | 限制与行为 |
| --- | --- | --- |
| `path` | 字符串 | 必填，已有本地视频 |
| `duration` | 数值 | 必填，大于 0 且不超过 3600 秒；按帧率量化，至少 1 帧 |
| `start` | 数值 | 默认 0，非负秒数 |
| `caption` | 字符串 | 可选，每镜一个 SRT 条目，允许单换行，不接受连续空行 |
| `visual_type` | 字符串 | 可选，`live` / `data` / `illustration` / `ai-illustration` / `unspecified` |
| `source_note` | 字符串 | 可选，来源与示意说明，写入报告，不烧录到画面 |

若有 `ai-illustration` 且字幕没有“AI”或“示意”，脚本会在 dry-run 与报告中提醒人工确认标注；它不判断科学正确性或许可有效性。时长按帧率量化后的值同时用于拼接、字幕与报告，避免非整帧时长的累积偏移。

输出遵循不覆盖约定：`x.mp4`、`x.report.json` 及需要时的 `x.srt` 任一已存在即失败。编码临时文件放在输出父目录内的专用临时目录，失败时仅清理本次临时目录；不会删除用户输入素材。

当前音频行为始终是替换：无 `soundtrack` 输出 AAC 静音音轨，有则输出该配乐的循环截取版本，输入片段的音轨都不进入成片。仅产生外置字幕，没有字幕烧录、转场、旁白生成、原音混合或响度标准化。

示例素材文件并不随包提供。可使用团队已有片段，或者运行 `scripts/smoke_test.py --workdir 新测试目录 --ffmpeg 可执行文件路径` 创建色块测试；该测试不需要联网。
