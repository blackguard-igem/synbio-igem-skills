# 操作指南

## 从选题开始

提供以下信息即可开始：观众是谁、希望观众学会什么、预计时长、横竖画幅、参考资料、已有素材。推荐请求示例：

> 使用 $synbio-video，给高中生制作一支 45 秒的课程导入视频，解释为什么合成生物学项目需要反复测试。请先整理分镜，区分已知事实和教学类比，不编造本队实验结果。目前没有视频生成工具。

检查分镜中的每个科学结论及来源。对比“设计目标”“已发表研究结果”“本队实测结果”，避免在文案中混用。镜头中的 AI 示意应在字幕、画面或随片说明中明确标示，报告文件中的标示并不会自动出现在 MP4 中。

## 合成本地片段

1. 准备 Python 3.9+ 和 FFmpeg。先执行 `python --version` 与 `ffmpeg -version`，确认使用的是预期版本。如果系统中有多个 FFmpeg，用 `--ffmpeg` 指定完整可执行文件路径。
2. 复制 `assets/manifest.example.json` 到自己的项目目录，填入已有片段路径和时长。路径相对于 JSON 所在目录；样例不附带视频。
3. 在本 Skill 目录运行：

```sh
python scripts/compose_video.py /path/to/project/manifest.json --dry-run
python scripts/compose_video.py /path/to/project/manifest.json --ffmpeg /path/to/ffmpeg
```

Windows 示例（在 PowerShell 中）：

```powershell
python scripts/compose_video.py 'D:/project/manifest.json' --dry-run --ffmpeg 'C:/Tools/ffmpeg/bin/ffmpeg.exe'
python scripts/compose_video.py 'D:/project/manifest.json' --ffmpeg 'C:/Tools/ffmpeg/bin/ffmpeg.exe'
```

`--dry-run` 会解析清单、检查本地素材存在性、输出规范化时间线及命令数组，不创建目录或媒体，不表示 FFmpeg 已成功编码。实际合成会先检查编码器及滤镜，并在新建临时目录编码；成功后发布文件。输出文件、同名 SRT 或报告已存在时拒绝覆盖，修改清单的 `output` 使用新版本名称即可。

脚本丢弃所有输入片段中的声音，即使素材有音轨。`soundtrack` 为空时生成静音轨；指定后用该音频作为整片替换音轨，短于全片时循环，长于全片时截取。它不会把配乐混入原声，也不会执行自动音量归一化。

每段 `duration` 是目标长度，按输出帧率四舍五入到整帧；不足的片段冻结最后一帧补足。`start` 超出视频结尾的空片段会导致失败，请修正清单。字幕一镜一条，可包含换行；不要用连续空行，避免破坏 SRT 条目。复杂逐词字幕应交给专用剪辑工具。

## 结果检查与故障处理

成功产生 `output.mp4`、`output.report.json`，有字幕时另有 `output.srt`。报告中写明实际编码参数、计划时长、音频模式和文件清单。打开视频，检查片头、每个切点和片尾，手动加载 SRT，试听配乐，核对素材是否有缺帧、拉伸、遮挡或错误科学表达。

- 找不到 FFmpeg：提供 `--ffmpeg` 完整路径，不会自动下载依赖。
- 缺编码器或滤镜：换用已安装且具备所列能力的 FFmpeg，报错会列出缺项。
- 输出已存在：使用新输出文件名；工具不提供覆盖参数。
- 某素材无法解码或 `start` 越界：先用播放器检查源文件，修正路径/时间，重新运行。
- 需要人声、原声、转场或烧录字幕：在支持这些功能的编辑器继续处理，不能把当前文件标成已经完成这些项目。

字段与限制详见 [清单格式](../references/manifest.md)。官方技术依据：[FFmpeg 滤镜文档](https://ffmpeg.org/ffmpeg-filters.html)、[FFmpeg 命令行文档](https://ffmpeg.org/ffmpeg.html)，核验日期 2026-09-14；实际可用能力以本机版本检查为准。
