# Operation Guide

## Start with the topic

Provide the audience, desired learning outcome, approximate duration, portrait/landscape format, reference sources, and available assets. Example:

> Use $synbio-video to plan a 45-second lesson-introduction video for high-school students explaining why synthetic biology projects require repeated testing. Start with a storyboard, distinguish established facts from teaching analogies, and do not invent results from our experiments. No video-generation tool is available yet.

Check each scientific claim and its source in the storyboard. Keep “design goal,” “published research result,” and “our measured result” distinct. If a shot uses AI-generated imagery, label it clearly in the subtitles, image, or accompanying notes; a label in a report does not automatically appear in the MP4.

## Compose local clips

1. Prepare Python 3.9+ and FFmpeg. Run `python --version` and `ffmpeg -version` to confirm the expected versions. If multiple FFmpeg builds are installed, pass the full executable path with `--ffmpeg`.
2. Copy `assets/manifest.example.json` to your project folder and fill in existing clip paths and durations. Paths are relative to the JSON file. The example does not include video clips.
3. From this Skill's directory, run:

```sh
python scripts/compose_video.py /path/to/project/manifest.json --dry-run
python scripts/compose_video.py /path/to/project/manifest.json --ffmpeg /path/to/ffmpeg
```

PowerShell example on Windows:

```powershell
python scripts/compose_video.py 'D:/project/manifest.json' --dry-run --ffmpeg 'C:/Tools/ffmpeg/bin/ffmpeg.exe'
python scripts/compose_video.py 'D:/project/manifest.json' --ffmpeg 'C:/Tools/ffmpeg/bin/ffmpeg.exe'
```

`--dry-run` parses the manifest, checks that local assets exist, and prints the normalized timeline and command array. It creates no directory or media and does not prove FFmpeg encoding will succeed. A real compose first checks encoders and filters, encodes in a new temporary directory, and publishes the output on success. It refuses to overwrite an existing output, same-name SRT, or report; use a new `output` filename in the manifest.

The script discards audio from every source clip, even if it has an audio track. An empty `soundtrack` creates a silent track. If one is provided, it replaces the entire soundtrack; a short music file loops and a long one is trimmed. The tool does not mix music with source audio or automatically normalize loudness.

Each `duration` is the target length, rounded to a whole output frame. The final frame is frozen to fill a short clip. An empty clip caused by `start` being beyond the end of the source fails; fix the manifest. Subtitles provide one entry per shot and may contain line breaks. Avoid repeated blank lines that could corrupt SRT entries. Use a dedicated editor for complex word-by-word captions.

## Review results and troubleshoot

Successful output includes `output.mp4` and `output.report.json`; when subtitles are specified, `output.srt` is also produced. The report records encoding parameters, planned duration, audio mode, and asset list. Play the video, inspect its opening, every cut, and ending; load the SRT manually, listen to the music, and check for missing frames, stretching, obstruction, or inaccurate science.

- FFmpeg not found: provide its full path with `--ffmpeg`; dependencies are not downloaded automatically.
- Missing encoder or filter: use an installed FFmpeg build with the required capabilities; the error lists missing items.
- Output already exists: choose a new output filename; the tool has no overwrite option.
- Clip cannot decode or `start` is out of range: check the source in a player, fix its path/time, and run again.
- Need voice, original sound, transitions, or burned-in subtitles: finish in an editor that supports them. Do not label the current output as containing those features.

See the [manifest reference](../references/manifest.md). Official technical references: [FFmpeg filters](https://ffmpeg.org/ffmpeg-filters.html) and [FFmpeg command-line documentation](https://ffmpeg.org/ffmpeg.html), checked 2026-09-14. Actual capabilities depend on the locally installed build.
