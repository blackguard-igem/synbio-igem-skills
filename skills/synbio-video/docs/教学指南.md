# 教学指南

目标学员：高中生、合成生物学入门学生或初次制作项目介绍的队伍。先修要求是能读懂所选科普材料，不要求已经完成湿实验。

## 一次 90 分钟练习

| 时间 | 学生活动 | 教师观察 |
| --- | --- | --- |
| 0—15 分钟 | 阅读教师提供的一个有明确出处的研究摘要，列出两条可支持的陈述 | 是否把论文结果夸大成普遍结论 |
| 15—35 分钟 | 把其中一条陈述改成 30—45 秒讲解，标出类比和未知项 | 类比是否被当成真实机制 |
| 35—55 分钟 | 设计镜头与字幕，为每个画面标“实拍 / 图表 / AI 示意” | 图表是否有数据来源，AI 示意是否可识别 |
| 55—75 分钟 | 用教师准备的无敏感数据片段填写 JSON 并 dry-run；条件允许再合成 | 是否理解帧率、时长、原声丢弃的影响 |
| 75—90 分钟 | 两组交换审核，指出一处表达清楚的地方和一处证据不足的地方 | 是否用来源和可见信息给反馈 |

课堂上可先播放同一概念的“目标陈述”和“实验结果陈述”，让学生判断差异。AI 给出完整脚本前，先请学生写自己的解释；随后比较内容、来源和遗漏，避免仅复制答案。

## 评价量规

四个维度各 0—2 分：科学内容与来源对应；对受众清楚易懂；事实、目标与示意区分；交付文件可播放且状态准确。0 分表示缺失或明显错误，1 分表示部分完成，2 分表示证据或检查结果充分。总分 6 分以上可进入修改成片阶段，但科学内容为 0 分时应先纠正，不能用其他分数抵消。

教师负责审阅可能被理解为实验操作指导的内容，检查受众是否会把画面模仿为未经指导的实验步骤。本教学练习可使用抽象流程、色块、工程迭代图和公开示意，不需要实际实验。

提交材料：分镜、来源表、素材表、dry-run 结果或 MP4/SRT、学生自己写的两条修订理由。没有生成条件时，按脚本与分镜评价，并在作业上记录“未生成成片”。
