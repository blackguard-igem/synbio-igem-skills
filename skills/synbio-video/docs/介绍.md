# 合成生物学科学媒体转译 · v1.1.0

适合教师、学生团队和科普策划人员，把论文解读、课程主题或项目介绍转化为视频材料。它提供科学脚本与分镜工作法，以及一个使用现有片段的本地合成工具。

| 输入 | 可交付结果 |
| --- | --- |
| 主题、受众、时长、参考资料 | 带来源的脚本、分镜、素材需求 |
| 本地视频片段和 JSON 清单 | 统一尺寸、帧率后的 MP4 |
| 每个镜头的字幕文本 | 与镜头时间对应的外置 SRT |
| 用户提供并可使用的配乐文件 | 替换全部原音的配乐版本 |

生成工具未连接时，仍可完成脚本和制作清单，但不能直接从文字生成视频。本包不内置云服务密钥，也没有将参考手册中的特定模型接口当作当前可用能力。

本地工具使用 Python 3.9 或以上版本、FFmpeg。Python 部分只有标准库依赖。FFmpeg 必须提供 `libx264`、AAC 编码器和脚本使用的滤镜；不随包分发 FFmpeg 二进制。可通过 `--ffmpeg` 指定本机可用版本。本地测试结果仅证明记录中的环境，Windows / macOS / Linux 的实际编解码器支持应通过本机试运行确认。

v1 的边界很明确：硬切拼接、等比例缩放加黑边；过短片段在尾部冻结补足清单时长；全片静音或单一替换配乐；不保留原音，不自动配音、不做转场、不烧录字幕、不自动发布。SRT 支持中文，但可见性取决于播放器加载字幕。

改编基础为项目提供的 AIGC 视频手册中的“需求拆解、代表性试片、合成、检查交付”思路。本包的文本与脚本重新编写，不复制其未确认授权的实现代码。
