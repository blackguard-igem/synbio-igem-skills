# Synthetic Biology Science Media Translation · v1.1.0

For teachers, student teams, and public-engagement organizers turning paper summaries, course topics, or project introductions into video material. The Skill provides a science-script and storyboard workflow, plus a local tool for composing existing clips.

| Input | Possible deliverable |
| --- | --- |
| Topic, audience, duration, reference sources | Sourced script, storyboard, and asset requirements |
| Local video clips and a JSON manifest | MP4 clips normalized to consistent size and frame rate |
| Subtitle text for each shot | External SRT timed to shots |
| User-provided music that may be used | Music version replacing all original audio |

If video-generation tools are unavailable, the Skill can still produce a script and production checklist, but it cannot create video directly from text. This package contains no cloud-service key and does not treat a model interface described in a reference manual as a currently available capability.

The local tool requires Python 3.9+ and FFmpeg. The Python code uses only the standard library. FFmpeg must provide `libx264`, an AAC encoder, and the filters used by the script; FFmpeg binaries are not distributed in this package. Use `--ffmpeg` to select an available local build. Recorded tests apply only to their stated environment; check actual codec support by running the tool on the target Windows, macOS, or Linux machine.

The v1 scope is intentionally limited: hard cuts, aspect-preserving resize with letterboxing, freezing the last frame when a clip is too short, and either silence or one replacement soundtrack. It does not retain original audio, auto-narrate, add transitions, burn in subtitles, or publish automatically. SRT supports Chinese, but visibility depends on the player loading the subtitle file.

The workflow adapts the provided AIGC video manual's ideas of breaking down requirements, testing a representative clip, composing, and checking delivery. This package's prose and scripts were rewritten; it does not copy implementation code whose licensing was unconfirmed.
