# 来源与改写说明

用户提供的 `memos-kb` 仅作为需求背景：团队希望资料可导入、可查询、可追踪。实现没有沿用其云端接口、数据结构、操作命令或文案，而是从“本地、项目隔离、可复核出处”三个约束重新设计，使用 Python 标准库 SQLite 完成证据账本与关键词检索。

原参考包包含固定配置，并未提供可确认的再分发许可。本发布目录没有复制原程序、长篇说明、账号、用户标识、知识库标识或凭据，也不依赖原包才能运行。概念参考不代表 MemOS 官方适配、合作或认证。

状态 `READY` 是本地导入状态。任何未来远程状态、文件编码、限流和查询接口都须重新按官方文档验证，不沿用原包的特定版本假设。
