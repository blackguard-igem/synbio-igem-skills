# 来源、提取与版本规范

每份资料至少保留：原文件路径或公开 URL、题名、作者或机构（已知时）、日期／版本、原文页码或节名、提取方式、提取时间，以及笔记中哪些是原文概括、哪些是个人推断。

导入 `.md` 和 `.txt` 时脚本记录规范化正文的 SHA-256、导入路径、稳定来源标识、位置文字、版本和 UTC 时间。版本号只反映本地记录变化，不等于论文修订版本。数据库仅保留最新正文；需要历史时在外部版本管理或备份中保存。

PDF／DOCX 不由本脚本解析。使用当前环境可用的文档提取工具先生成 UTF-8 文本，人工检查关键段落。PDF 建议按页或连续小节提取，标明“原文第 N 页”；Word 可保留标题层级、表格编号和段落位置，除非有固定版式版本，不编造页码。

扫描件须记录 OCR，并核对关键数字、单位、图注和否定词。表格、公式、上下标和图像在提取时可能丢失，检索结果不足以回答时返回原文检查，不声称文本索引包含所有内容。

来源标识示例（仅格式示范）：`paper-note:figure-2`、`meeting:2026-09-14:decision-1`。同项目同标识被视为同一个可更新记录；分块应有不同标识，并在正文共同指向原资料。一个块的 `locator` 只描述该块已知位置；命中行号是导入正文行号。

数据库以普通文件储存，文件系统权限、备份和共享范围由用户环境管理。不要把账号、API Key、私人联系方式等凭据类材料导入；脚本不提供自动脱敏，也无法代替人工审核。不能在没有用户授权的情况下上传资料或把其他项目内容复制入当前项目。
