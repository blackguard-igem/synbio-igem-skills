# 合成生物学知识库：介绍

版本：1.1.0。面向团队资料负责人、教师与项目导师。本版将本地资料定义为“项目证据账本”，检索回答固定区分原文命中、解释与待核验问题。

本 Skill 把用户指定的 Markdown 或纯文本存入本地 SQLite 数据库，可添加、列出、按关键词搜索并读取全文。每条记录包含项目、来源、原文位置说明、导入路径、内容哈希、版本和时间；搜索结果含命中行号，便于 AI 回答后追溯。

开箱即用的条件是 Python 3.10+，无需第三方库或云账号。脚本不会联网、上传、自动读取其他目录或收集个人凭据。所有操作由用户明确给出文件、数据库和项目名。

这是关键词检索，不是向量或语义检索；中文用明确词组，多个词之间用空格。它适合小型项目资料包、课程笔记和经过整理的文献摘要，不适合直接索引大型文献仓库。PDF、Word 和网页需要先由适当工具提取文本并保留来源。

项目名限定命令的查询范围，但数据库没有账号认证、加密或操作系统级权限分离；能读取数据库文件的人可以查看其中全部项目。团队共享部署需要另加访问控制，不能把 CLI 命名空间当作多租户安全系统。

本版本只保存每个来源的当前版本和版本号，不保存旧正文历史，不自动同步源文件。再次运行 `add` 才更新；需要历史回溯时，在用户项目中另外保存文档版本或备份数据库。

原 MemOS Skill 的资料格式、处理状态和查询范围经验被用于需求设计。本版程序为原创本地实现，不含原包凭据，也不内置远程 API。未来需要 MemOS 时可按 [接入检查](../references/optional-memos.md) 单独开发。
