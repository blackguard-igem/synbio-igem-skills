# Synthetic Biology Knowledge Base: Overview

Version 1.1.0. For team information managers, teachers, and project mentors. This release treats local materials as a “project evidence ledger”; search answers distinguish source-text matches, interpretation, and questions that still need verification.

The Skill stores user-selected Markdown or plain text in a local SQLite database. It can add, list, search by keyword, and retrieve full text. Each record includes a project, source, source-location note, import path, content hash, version, and timestamp. Search results include matching line numbers to make later tracing possible.

Requirements: Python 3.10+; standard library only; no cloud account. The scripts do not connect to the internet, upload files, automatically read other directories, or collect credentials. Users explicitly provide the files, database, and project name for every operation.

This is keyword search, not vector or semantic search. Use explicit phrases for Chinese, separating multiple terms with spaces. It suits small project collections, course notes, and curated paper summaries, not a large literature corpus. Extract text from PDFs, Word documents, and web pages with appropriate tools while preserving source information.

The project name limits command queries, but the database has no account authentication, encryption, or operating-system-level permission separation. Anyone who can read the database file can view all projects in it. A shared team deployment needs additional access controls; CLI project namespaces are not a multi-tenant security system.

This version stores only the current text and version number for each source; it does not retain previous text or synchronize source files automatically. Running `add` again updates the record. Keep document versions or a database backup in the user's project when historical recovery is needed.

The original MemOS Skill informed requirements around source format, processing status, and query scope. This program is an original local implementation; it contains no credentials from the original package and no remote API. If MemOS is needed later, develop it separately using the [integration checklist](../references/optional-memos.md).
