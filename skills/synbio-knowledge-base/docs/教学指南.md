# Synthetic Biology Knowledge Base: Teaching Guide

Learning goals: students can import notes with sources, distinguish source text from their own interpretation, verify search results, and explain why a keyword match is not proof of a fact. Basic file handling is the only prerequisite; database knowledge is not required.

## 45-minute teaching simulation: Trace a source

Use only the [demo note](../examples/demo-note.md), not real team records or personal information. The teacher first demonstrates `add` and `search`; students complete the exercise in a new demo database.

| Time | Task | Observable learning outcome |
| --- | --- | --- |
| 10 min | Import the demo material and explain `source` versus `locator` | Identify the source ID and original-text location separately |
| 10 min | Search by keyword and verify with `get` | Report the correct project, version, source, and line number |
| 10 min | Edit a personal copy and import again | Explain `updated` versus `unchanged` and identify the current version |
| 10 min | Search another demo project | Explain why no match does not mean no material exists anywhere |
| 5 min | Exit ticket | State one conclusion that a search match alone cannot prove |

Assess four abilities: tracing a source back to its text, keeping summaries within the evidence, explaining version updates, and not crossing project boundaries to obtain an answer. Record each as “not demonstrated / partly complete / independent,” with the student's own explanation.

Common misconceptions include treating keyword frequency as credibility, stored as reviewed, no match as nonexistence, and an AI-generated note as an original paper. Correct them by asking students to return to one source and one specific claim; increasing the number of searches is not a substitute for evaluating evidence.

For an advanced exercise, add two real public sources with different research scopes after the teacher checks suitability and usage rights. Record PDF page numbers separately from imported-text line numbers. OCR can misread symbols, units, and negation, so students should check key claims against the original page.

The Skill's teaching value is source management and citation practice. It does not assess whether a biological proposal is scientifically correct; a teacher or expert research workflow should review content when needed.
