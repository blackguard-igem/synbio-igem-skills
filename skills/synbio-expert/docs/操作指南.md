# 操作指南

## 调用

将整个 synbio-expert 文件夹安装到支持 SKILL.md 的Agent技能目录，或由团队的Agent运行器读取SKILL.md及按需引用的文件。平台是否自动发现技能取决于宿主；单独上传本说明书不会自动安装脚本或工具。

可直接提问：

> 使用 $synbio-expert。我是高中生，知道DNA和蛋白质，但不理解基因回路。请用一个例子解释，并用两道问题检查我是否理解。

> 使用 $synbio-expert。根据附件论文，区分作者直接证明的结论、作者解释、尚未解决的问题。告诉我你实际读到了哪些部分。

> 使用 $synbio-expert。介绍陈国强团队的研究方向，给出官方出处，再设计一个不涉及湿实验的讨论活动。

## 提供合适的信息

问题中可包含受众、任务目标、已有资料、时间与设备限制。缺少信息也可以先开始；AI应说明哪些判断依赖缺失条件。需要比较方案时使用 [评审模板](../assets/review-template.md)，未知项保留空白或写“未提供”。

检查结果时重点看：引用是否真能支持对应句子；模型与研究对象是否一致；学生项目是否被误写成取得了文献里的成绩；假设是否清楚标出。

## 人物与资料维护

扩充专家使用 [档案模板](../assets/expert-profile-template.md)。同名人物先核验机构和方向，避免合并。职务、论文版本和网页更新分开记录。没有足够公开证据时，保持“资料介绍”模式。

保存研究记录需指定输出位置和项目。公共论文链接可共享，私有学生回答、未公开方案和个人联系方式不默认进入公共资料包。可选使用 synbio-knowledge-base 保存可追溯文本资料。

## 常见情况

- 论文打不开：提供可读文件，或只解读已取得的摘要；不补写看不到的细节。
- 回答太深：说明受众与先修知识，让AI先解释必要术语。
- 需要实验实施：补充实际目标、系统、已批准流程和导师背景；本Skill本身不是实验室批准文件。
- 需要时间表与课程：将研究结论交给 synbio-planner，或直接请求文本计划。
