# Operation Guide

## Invoke the Skill

Install the entire `synbio-expert` folder in an agent's Skill directory, or configure the team's agent runner to read `SKILL.md` and referenced files on demand. Automatic discovery depends on the host. Uploading this guide alone does not install scripts or tools.

Example prompts:

> Use $synbio-expert. I am a high-school student and understand DNA and proteins, but not gene circuits. Explain with one example and check my understanding with two questions.

> Use $synbio-expert. From the attached paper, distinguish what the authors directly demonstrated, how they interpret it, and what remains unresolved. Tell me which parts you were actually able to read.

> Use $synbio-expert. Introduce the research areas of Guoqiang Chen's group, give official sources, and design a discussion activity that does not involve wet-lab work.

## Provide useful context

Include the audience, task goal, available materials, time, and equipment constraints when known. You can start without every detail; the AI should identify judgments that depend on missing information. For comparisons, use the [review template](../assets/review-template.md). Leave unknown fields blank or mark them “not provided.”

When checking an answer, ask whether each citation supports its sentence, whether the model matches the research subject, whether a student project has been falsely credited with a published result, and whether assumptions are clearly labeled.

## Maintain expert profiles and sources

Use the [profile template](../assets/expert-profile-template.md) to add an expert. Verify affiliation and research area before combining people with the same name. Track appointments, paper versions, and web-page updates separately. If public evidence is insufficient, keep the profile descriptive rather than making unsupported claims.

Specify the destination and project when saving research notes. Public paper links may be shared; private student responses, unpublished plans, and personal contact details should not be added to a public package by default. `synbio-knowledge-base` is an optional way to store traceable text sources.

## Common situations

- Paper cannot be opened: provide a readable copy or limit analysis to the accessible abstract; do not invent unseen details.
- Answer is too advanced: state the audience and prior knowledge, and ask for prerequisite terms to be explained first.
- Experimental implementation is needed: provide the actual goal, system, approved procedures, and supervisor context. This Skill is not laboratory authorization.
- A schedule or course is needed: pass research conclusions to `synbio-planner` or request a text plan directly.
