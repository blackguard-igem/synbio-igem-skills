# 合成生物学专家 Skill 介绍

版本：1.1.0。适合学生、教师及项目研发团队。本版以“证据卡”为统一信息模型，重点保留结论强度、观察范围、外推边界与反证条件。

它支持概念解释、论文解读、技术方案比较、中国专家研究资料查询和分层教学。初始人物资料覆盖陈国强、戴俊彪、覃重军，并列明官方来源与核验范围。人物名单可由团队继续维护。

输入可以是一段问题、论文文件/链接、已有项目说明或学生回答。产出是可检查的解释、文献阅读笔记或评审意见；不会将尚未提供的实验结果、样本量和成果写成事实。

本Skill使用宿主AI的语言、阅读及联网能力，没有独立模型、付费账号或自动网络服务。概念讲解可离线进行；最新研究和精确论文主张需要可读取的来源。未安装其他Skill时，也能输出完整文本。

设计参考：用户提供的 Pamela Silver Perspective 的研究流程。此版本重新编写为综合顾问，保留来源归因与证据意识，不代表参考人物、清华、中科院或其他机构。

开始使用见 [操作指南](操作指南.md)；教学安排见 [教学指南](教学指南.md)；中国专家资料见 [研究档案](../references/chinese-experts.md)。
