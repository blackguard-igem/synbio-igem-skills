# 教学指南

## 教学目标

学习者能解释一个生物系统的输入、作用机制和输出；能区分证据与推断；能提出一个会改变自己判断的问题。按学生基础选择任务，不能只按年龄推定能力。

## 三个层次

| 层次 | 学习活动 | 可观察的成果 |
|---|---|---|
| 入门 | 解释一个概念；指出类比成立和失效的位置 | 用自己的话解释并回答迁移题 |
| 进阶 | 对照论文中的图与结论，寻找对照和局限 | 一页证据笔记，每个结论有位置 |
| 项目 | 比较两个候选思路及其可测量结果 | 说明选择理由、缺口与下一步 |

## 45分钟示例课：科学主张需要什么证据

以下课时由编写者设计，是教学示例。

1. 5分钟：学生分别解释“某系统可工作”和“某系统适合真实使用”。记录原始回答。
2. 10分钟：选择中国专家资料中的一个主题。教师展示实际取得的官方介绍或论文片段，标出来源类型。
3. 10分钟：学生将三条句子分为已知事实、解释、待验证假设，并说明依据。
4. 10分钟：同伴提出一个改变条件的情况，学生判断原结论能否外推。
5. 10分钟：学生修改一条过度表述，并写出需要的补充证据。AI先给提示，随后展示一种参考分析。

## 提示与反馈

先要求学生陈述理解或理由；卡住时给相关概念和一条线索。学生仍不能推进时示范一个类似问题，再请学生处理原问题。用户明确请求示范答案时可以直接给，并解释推理。

评价依据：机制是否合理、证据是否匹配、是否承认局限、是否能迁移。用“已做到／需补充／尚未观察到”及具体例子记录，不把答题流畅度等同于理解，也不虚构学习提升百分比。

## 教师与AI分工

教师选择可信材料、调整难度和核对科学内容；AI提供解释、追问和整理。实验课使用机构批准的教学条件与流程。人物角色用于比较公开研究方法，不替代证据或教师判断。
