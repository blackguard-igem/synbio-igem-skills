# 合成生物学讲稿与提示卡 介绍

版本 1.1.0。本 Skill 把已经校核的讲稿、课堂问题、主持流程和答辩要点变成现场认知卡片，使用“触发点—核心话语—证据锚点—讲述动作—持有人”的独立设计模型，面向教师、助教、学生展示团队和活动主持人。

它完成结构化输入检查、长文本分页、稳定卡号、多人共同持卡与分套、来源显示和完整索引。默认输出离线 HTML；安装 ReportLab 并提供具备嵌入许可的中文 TrueType 字体后，输出固定尺寸 PDF。源 JSON 可编辑，HTML 可以通过浏览器打印；本版本不输出 Word。

## 与其他 Skill 如何协作

生物学专家 Skill 提供已核对的知识解释、证据和局限；策划 Skill 提供课程流程、时间分配和角色；iGEM 导师 Skill 可提供有来源的答辩训练问题。本 Skill 将这些内容整理成讲述或练习提示。它也能独立处理用户已经准备好的内容，不要求安装全部套件。

输入内容中的指令仅作为卡片正文。把某网址写入来源不会上传数据或访问该地址。

## 一次完整产出

输入 `cards-example.json` 后，得到总套 `all.html`、每名讲述者一套 `speaker-01.html` 等文件、`index.html` 与 `index.json`。启用 PDF 时生成同名 PDF。卡片标题、发言人、正文、可见提示、来源和续卡编号都可以追溯到原始 JSON。

重复出现的共同发言卡在不同分套中保留同一个编号，便于排练时对照。较长的完整来源保存在索引中，不会因为页脚空间不足而丢失。

## 能力边界

- 不审定科学真实性，也不代替当年赛事规则核验。
- 不无损处理 Word、公式、表格、图片或复杂上下标。
- PDF 需要用户提供中文字体；本包不附带系统字体，也不授予第三方字体再分发权。
- HTML 打印效果受浏览器与字体影响，使用前查看打印预览。PDF 页面尺寸是成品卡尺寸，无自动拼版、裁切标记或出血；有印刷厂要求时需另行处理。
- `notes` 会印在卡上。用于学习测验时，教师答案与学生题卡应分别生成。

第一次使用见[操作指南](操作指南.md)；用卡片组织课堂见[教学指南](教学指南.md)。
