# Synthetic Biology Speaker and Cue Cards: Operation Guide

## Environment and first run

Requires Python 3.10 or later. Open a terminal in this Skill directory and try the HTML mode first; it needs no third-party package:

```sh
python scripts/cue_cards.py assets/cards-example.json --out cards-html
```

Open `cards-html/index.html` to see the full deck, speaker decks, and original sources, then open a specific HTML file. Print at 100% scale with browser headers and footers off. One card is printed per page; the default size is 150 × 100 mm. Do not mistake automatic page scaling for the actual type size of a handheld card.

PDF mode needs installed dependencies and a font path. Windows PowerShell example:

```powershell
python -m pip install -r requirements.txt
python scripts/cue_cards.py assets/cards-example.json --out cards-pdf --format both --font 'C:/Windows/Fonts/msyh.ttc'
```

On macOS/Linux, pass an absolute path to a locally licensed, embeddable `.ttf` or TrueType-containing `.ttc` font using `--font`. TTC uses font index 0 by default; use `--font-index 1` to select another. ReportLab does not support every OTF/CFF font. Incompatible fonts or missing glyphs produce an error. Do not copy system fonts into the release package.

Print a sample PDF card to check handheld reading distance and type size. HTML and PDF use different font measurement; page counts may differ. When `--format both` is used, HTML and PDF share PDF pagination, but local fonts may still change line widths in the HTML preview.

## Input format

The root object requires `version: "1.0"`, `deck_title`, and a non-empty `cards` array. Unknown root or card fields cause an error so a typo cannot silently drop content.

| Field | Type | Purpose |
| --- | --- | --- |
| `title` | Non-empty string | Card topic; shorten if it cannot fit on two lines |
| `speaker` | Non-empty string or array of strings | Speaker; an array means every listed person holds this card |
| `body` | Non-empty string | Main text; use `\n` for paragraphs; pagination prefers sentence boundaries |
| `notes` | Optional string | Visible printed prompt, not a hidden answer |
| `source` | Non-empty string | Actual source, reference ID, URL, or note that the content is original |

Text is processed as plain text; HTML tags are escaped, not executed. `body` and `notes` are split at periods, question marks, exclamation marks, semicolons, or line breaks; a single segment that cannot fit is split across lines. Source JSON and the index retain the original fields; pagination does not change evidentiary meaning.

Copy `assets/cards-template.json` and fill it in. If a source has not been verified, label it “to be checked” and treat the cards as a draft, not as established facts for students.

## Options and layout

```sh
python scripts/cue_cards.py my-cards.json --out rehearsal-v2 --format html --width-mm 150 --height-mm 100 --body-pt 14
```

| Option | Default | Description |
| --- | --- | --- |
| `--out` | Required | New output directory; existing directories are not overwritten |
| `--format` | `html` | `html`, `pdf`, or `both` |
| `--font` | None | Required local font path in PDF mode |
| `--font-index` | `0` | TTC font index |
| `--width-mm` | `150` | Page width, 100–250 mm |
| `--height-mm` | `100` | Page height, 70–210 mm |
| `--body-pt` | `13` | Body size, 10–24 pt; page must fit at least three body lines |

The full deck (`all`) and speaker decks (`speaker-01`, etc.) share card IDs. For example, `C003-02/03` is continuation 2 of 3 for original card 3. The index maps each speaker deck to speaker names. Filenames do not use user-provided names, avoiding special-character and path issues. Even PDF-only output includes `index.html` and `index.json` to verify sources and numbering.

The tool writes into a temporary directory and moves the finished output as a whole. A failure does not leave a partial deck.

## Teacher and student decks

1. Save a teacher JSON file with answer prompts.
2. Copy it for the student version; remove `notes` that reveal answers but retain questions and real sources. Give students different prompts if useful.
3. Write the two versions to separate new output directories. Check the student deck for answers before distribution.

Do not merely make hints white or shrink the type; the text would still be present in the file.

## Common errors

- `Output already exists`: choose a new output directory.
- `PDF requires --font`: supply a Chinese font, or start in default HTML mode.
- `Font is missing characters`: choose a font covering those glyphs; do not accept empty boxes.
- `Title is too long` / `Speakers are too long`: shorten the header label and put the full explanation in the body or index; do not silently crop it.
- `Page leaves fewer than 3 body lines`: enlarge the card or reduce text, then preview again.
- Permission denied or output path is a file: choose a writable directory. The program returns a nonzero exit code with an error.

Before use, verify speaking order, speakers, shared-card assignments, continuation flow, answer leakage in the student deck, and whether each source can be found. Fixed PDF layout does not replace scientific-content review.
