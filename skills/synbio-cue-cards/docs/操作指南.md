# 合成生物学讲稿与提示卡 操作指南

## 环境与第一次运行

需要 Python 3.10 或更新版本。在本 Skill 目录打开终端，先试运行无第三方依赖的 HTML 模式：

```sh
python scripts/cue_cards.py assets/cards-example.json --out cards-html
```

打开 `cards-html/index.html` 查看总套、分套及原始来源，再打开对应 HTML。打印设置使用 100% 比例，关闭浏览器页眉页脚；一张卡一页，默认 150 × 100 mm。不要把页面自动缩放误认为实际持卡字号。

PDF 模式需要安装依赖并指定字体。Windows PowerShell 示例：

```powershell
python -m pip install -r requirements.txt
python scripts/cue_cards.py assets/cards-example.json --out cards-pdf --format both --font 'C:/Windows/Fonts/msyh.ttc'
```

macOS / Linux 也使用 `--font` 传入本机合法可嵌入的 `.ttf` 或包含 TrueType 字形的 `.ttc` 字体绝对路径。TTC 默认使用第 0 个字体，可通过 `--font-index 1` 选择其他字体。不是所有 OTF/CFF 字体都被 ReportLab 支持；字体不兼容或缺字时会报错。不要将系统字体直接复制进发布包。

PDF 应先打印一张样卡核对手持距离和字号。HTML 与 PDF 使用各自的字体测量方式，分页数量可能不同；同一次 `--format both` 的 HTML 与 PDF 共用 PDF 的分页结果，HTML 预览仍可能因本地字体差异改变行宽。

## 输入格式

根对象包含 `version: "1.0"`、`deck_title` 与非空 `cards` 数组。根对象与卡片中的未知字段会报错，避免拼错字段导致内容静默丢失。

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `title` | 非空字符串 | 卡片主题，过长无法放入两行时需缩短 |
| `speaker` | 非空字符串或字符串数组 | 发言人；数组表示每人都持有这张卡 |
| `body` | 非空字符串 | 正文；用 `\n` 分段，句末优先分页 |
| `notes` | 字符串，可省略 | 打印可见的提示，不是隐藏答案 |
| `source` | 非空字符串 | 真实出处、资料编号、URL 或原创说明 |

文本按纯文本处理，HTML 标签会转义，不会执行。`body` 与 `notes` 按句号、问号、感叹号、分号或换行切块；单块装不下一页时按行拆分。源 JSON 与索引保留原字段，换行排版不改变证据含义。

可复制 `assets/cards-template.json` 填入自己的内容。来源尚未核对时应明确写“待核对”，保留为工作稿，不把它作为已验证事实交付给学生。

## 参数与版式

```sh
python scripts/cue_cards.py my-cards.json --out rehearsal-v2 --format html --width-mm 150 --height-mm 100 --body-pt 14
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--out` | 必填 | 新输出目录；已存在会报错，不覆盖旧版 |
| `--format` | `html` | `html`、`pdf` 或 `both` |
| `--font` | 无 | PDF 模式必填的本地字体路径 |
| `--font-index` | `0` | TTC 字体编号 |
| `--width-mm` | `150` | 页面宽 100–250 mm |
| `--height-mm` | `100` | 页面高 70–210 mm |
| `--body-pt` | `13` | 正文 10–24 pt；页面必须容纳至少三行正文 |

总套 `all` 与分套 `speaker-01` 等文件共用卡号，如 `C003-02/03` 表示第 3 条原始卡的第 2 张续卡，共 3 张。索引显示每个分套对应的人名，文件名不使用输入的人名，避免特殊字符或路径问题。即使只输出 PDF，也会输出 `index.html` 和 `index.json`，以便核对来源和编号。

来源超过页脚三行时，卡片提示到 `index.html` 的指定卡号查看完整出处；索引必须随卡片文件一并保存。输出目录采用临时目录写入、完成后整体移动，失败不留下半套成品。

## 教师版与学生版

1. 保存教师版 JSON，保留回答提示。
2. 复制为学生版，删除透露答案的 `notes`，保留题目和真实出处；必要时给学生不同的思考问题。
3. 两份文件分别写入新输出目录，先检查学生版没有答案，再发放。

不要只把提示改为白色或缩小字号，这些内容仍然存在于文件里。

## 常见报错

- `Output already exists`：选择新的输出目录。
- `PDF requires --font`：提供中文字体，或先使用默认 HTML 模式。
- `Font is missing characters`：更换覆盖这些字的字体；不以空白方框代替。
- `Title is too long` / `Speakers are too long`：缩短页眉标签，完整说明放正文或索引；不能直接裁切。
- `Page leaves fewer than 3 body lines`：增大页面或减小正文，重新预览。
- 权限不足或输出路径是文件：选择可写目录；程序返回非零退出码并说明错误。

最终核对讲述内容、发言人、共同卡重复归属、续卡是否连贯、学生版是否漏出答案、每条来源能否找到。PDF 固定排版也不能替代科学内容检查。
