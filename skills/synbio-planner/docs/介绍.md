# Synthetic Biology Planner: Overview

Version 1.1.0. For project leads, teachers, public-engagement organizers, and iGEM teams. This release connects goals, execution, and review through outcome maps, dependency maps, and evidence gates.

The Skill helps a team decide why to act, what to do, how to divide work, and how to determine whether it is complete.

| Scenario | Inputs | Main deliverables |
| --- | --- | --- |
| Research / iGEM topic selection | Question, team capabilities, timeline, resources, candidate directions | Comparison, evidence gaps, milestones, responsibilities |
| Teaching | Student background, class time, learning goals, teaching conditions | Unit plan, activities, exercises, assessment rubric |
| Public engagement | Audience, topic, venue, duration, communication goals | Run of show, content roles, materials, feedback and contingencies |

A project may use several modes: select a research question first, prepare student training with the teaching mode, and then design a public showcase. Each mode retains its own success criteria: completing a class is not research validation, and attendance is not proof of learning.

The method turns goals into observable outcomes, compares alternatives, pilots a small version before scaling investment, updates the plan using evidence and feedback, and makes unknowns explicit. These are original organizational workflows informed by problem decomposition and example-first ideas in reference Skills; they do not represent any expert or official competition organization.

This is an AI workflow with supporting documents, not deployed project-management software. Basic use needs no external service; sufficient user-provided material can produce a draft. Web research can improve fact-checking, while separate document, spreadsheet, or media outputs require matching tools in the runtime. Without them, the Skill can still produce Markdown plans and copyable tables.

See the [operation guide](操作指南.md) and [teaching guide](教学指南.md). All examples are instructional simulations, not records of completed projects.
