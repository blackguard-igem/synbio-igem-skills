# 合成生物学策划：介绍

版本：1.1.0。面向项目负责人、教师、科普活动策划者与 iGEM 队伍。本版以成果图、依赖图和证据闸门连接目标、执行与复盘。

本 Skill 帮助团队决定“为什么做、做什么、如何分工、怎样判断完成”，适合三个场景：

| 场景 | 输入 | 主要交付 |
| --- | --- | --- |
| 科研／iGEM 选题 | 问题、队伍能力、周期、资源、候选方向 | 选题比较、证据缺口、里程碑、责任分工 |
| 课程教学 | 学生基础、课时、学习目标、授课条件 | 单元安排、课堂活动、练习、评价量规 |
| 科普活动 | 受众、主题、场地、时长、传播目标 | 流程、内容分工、物料、反馈与应急安排 |

同一项目可使用多个模式。例如先用科研模式决定问题，再用课程模式准备学生训练，最后用活动模式设计公众展示。每个模式都保留自己的验收标准，不把上完课当作研究验证，也不把参与人数当作学习效果。

核心方法包括：把目标改写成可观察成果；比较替代方案；在扩大投入前先做小范围试运行；用证据和反馈更新计划；将未知条件显式保留。它们是原创组织流程，吸收参考 Skill 的问题拆解和样例先行理念，不代表任何专家本人或官方竞赛机构。

这是给 AI 使用的工作流程与配套文档，不是已部署的项目管理软件。基础使用无需外部服务；用户提供足够材料即可形成草案。联网检索可提高事实核验质量，独立文档、表格或媒体输出需要运行环境提供对应工具。没有相关工具时，仍可输出 Markdown 计划与可复制表格。

入门看 [操作指南](操作指南.md)；教师组织团队学习看 [教学指南](教学指南.md)。所有示例均为教学模拟，不是已完成项目记录。
