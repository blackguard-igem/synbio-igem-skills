# 合成生物学策划：教学指南

本指南帮助教师用 AI 培养学生的策划能力。学生应保留提出问题、选择证据、作出取舍和解释决定的责任。

## 学习目标与起点

初学者应能区分“我们想帮助谁”“科学机制是什么”“项目怎样检验”；进阶学生应能比较替代方案、识别资源约束，并根据新证据修改计划。先用一个简短任务了解学生已有知识，而非凭年龄判断水平。

推荐教学循环：学生独立草拟一页计划 → AI 根据缺项提出少量追问 → 小组用来源支持选择 → 同伴评审 → 修订并解释一个实际改变。AI 可以示范提问，不应先替学生完成整份可直接提交的成果。

## 教学模拟：90 分钟策划练习

情境：一个虚构校园团队想通过公开资料研究“如何比较不同生物制造路线的证据成熟度”，不开展实验，也不声称某路线优于现实产品。

| 时间 | 活动 | 学生留下的证据 |
| --- | --- | --- |
| 0–10 分钟 | 写清问题、受众和已知约束 | 三句话需求说明 |
| 10–30 分钟 | 比较两个候选方向，分别列支持与反对理由 | 比较表与待核验来源 |
| 30–50 分钟 | 拆成任务、负责人角色和检查点 | 一页任务计划 |
| 50–70 分钟 | 交换评审，辨认一项未验证假设 | 带理由的同伴意见 |
| 70–90 分钟 | 修订并解释决定 | 修订前后对照与退出条 |

## 可调整的评价量规

以下分值是教学设计示范，由教师结合课程目标修改，不是官方 iGEM 评分标准。每维度 0–2 分：0 为缺失或误解；1 为部分清楚但依据或连接不足；2 为具体、可追溯且与任务一致。

| 维度 | 达到 2 分的可观察表现 |
| --- | --- |
| 问题界定 | 说明服务对象、范围与不解决的内容 |
| 证据使用 | 区分来源事实、推断与缺口，不伪造数据 |
| 可执行性 | 任务有责任角色、依赖、交付与验收方式 |
| 比较与取舍 | 解释为何选择此方案及放弃另一方案的代价 |
| 反思与修订 | 指出反馈改变了哪项决定，仍有什么不确定 |

形成性评价看过程文档与解释，结课评价可用修订计划加短答辩。不要仅按排版、术语数量或 AI 输出长度评分。

## 分层与教师介入

初学者给两三个已筛选的材料和半填模板；进阶学生自行检索并讨论来源冲突。常见误解包括把需求当方案、把推测当数据、把活动完成当效果证明。教师可问：“什么观察会让你修改这个决定？”对真实实验、个人数据收集、机构联系和竞赛正式提交，由相应负责人决定条件与授权，课堂模拟不能替代实际审查。
