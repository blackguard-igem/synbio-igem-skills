# 合成生物学策划：操作指南

## 开始一个任务

调用 `$synbio-planner`，说明需要科研项目、课程还是科普活动。把已知约束直接写进需求，不需要先填满所有字段。

可复制的输入：

```text
使用 $synbio-planner。
模式：课程教学
受众：高中阶段、学过基础遗传学的学生
目标：能区分科学问题、工程目标和检验证据
时间：4 次课，每次 60 分钟
资源：普通教室和联网电脑，不安排湿实验
人数：24 人，分 6 组
预算：暂未确定，请列待询价项，不填写实际金额
交付：课程总览、第一课教案、学习评价和任务分工
```

上述是输入示范，不代表真实班级或既定安排。完整教学模拟见 [四课选题工作坊](../examples/four-session-workshop.md)。

## 迭代计划

先检查草案中的目标、硬约束与假设，再审查任务是否有验收证据。可继续要求：“课时缩减到两次，请保留关键学习目标并解释删减”，或“设备不可用，请调整依赖它的任务”。更新时要求保留版本、变更原因与尚待决定事项。

预算可有三种状态：用户确认的金额、带计算依据的初步估算、待询价。不要把三种状态合并为一个看起来精确的总预算。负责人未确定时用“教学负责人”“资料负责人”等角色，不生成真实姓名。

## 使用模板

- [项目计划](../assets/project-plan.md)：科研问题、候选比较、证据与里程碑。
- [课程计划](../assets/course-plan.md)：学习目标、活动与评价的一一对应。
- [活动计划](../assets/event-plan.md)：受众路径、流程、物料和反馈。

复制模板到实际项目目录后填写，不把团队数据写回发布包。模板中的“待填写”是待用户项目补充的输入位，不是虚构结论。

## 交付前检查

计划应能回答：谁在什么时间交什么成果；如何知道成果合格；哪些条件不满足就需要延期或改方案；哪些数字是估算；哪些判断有来源。涉及 iGEM 时确认年份与官方来源，缺少核验材料则只交付通用策划并标注规则待核验。

可选让 `synbio-expert` 校核科学内容，让 `igem-mentor` 检查赛事映射，让 `synbio-knowledge-base` 检索本项目资料。未安装这些 Skill 不影响生成计划，不宣称已经调用不存在的能力。
