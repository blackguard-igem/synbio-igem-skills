# 来源与改写说明

本 Skill 从项目管理的功能需求独立设计：团队需要把目标转换为可观察成果、明确前置依赖，并用预先约定的证据决定继续、暂停或改线。发布入口采用“成果图—依赖图—证据闸门”信息模型，未沿用参考包的人物视角、步骤编号、表达框架或视频制作流程。

没有复制原 Skill 的人物语气、长段正文或程序；没有移植原包中的配置或凭据。参考包未提供可确认的再分发许可，因此本目录不附带其文件。这里的概念来源说明不构成 Pamela Silver 或任何原作者对本套件的授权、认可或共同开发声明。

人物事实、论文结论和 iGEM 当年规则不由此文件背书；实际任务涉及这些事实时，仍需读取相应原始来源。模板中的评价方式和示例均为本套件教学设计，不是官方竞赛标准。
