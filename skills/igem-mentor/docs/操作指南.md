# 操作指南

## 开始

将完整 igem-mentor 文件夹放入支持 SKILL.md 的Agent技能目录。自动发现与调用语法以所用平台为准；也可在平台的系统指令中加载本Skill并提供它引用的资料。

示例：

> 使用 $igem-mentor。我们是2026年高中新人队伍，请解释主要交付物、官网位置和下一步，给中文及英文摘要。

> 使用 $igem-mentor。请核验2026年注册费退费条件；我的付款日期尚未确定。请指出哪些信息还不足，不要猜测金额。

> 使用 $igem-mentor。整理某年份的Best Hardware获奖案例，分别提供官方获奖证据和队伍Wiki，不把你的分析写成评委评语。

## 检查一次答案

核对年份与组别；打开与主张对应的深层链接；确认引用来自实际政策而不是去年Wiki；比较中英两段是否保留同样条件；截止时间是否标时区；安全结论是否明确属于预检查。

如果AI无法打开官网动态页面，提供可读的官方PDF或正文，并注明来源、年份及取得日期。AI应明示资料范围。没有当年政策时可继续学习术语和准备框架，但不采用未核验金额或deadline做付款决策。

## 连续使用

可使用 [队伍状态模板](../assets/team-state-template.json)，填写组别、目标和已知事实。需要跨会话时保存到队伍自己的位置，并在下次加载；安装本Skill本身不会自动保存聊天。需要本地资料检索可另装 synbio-knowledge-base。

## 维护

根据当前官网更新 [资料目录](../references/official-sources.json)，保留实际核验范围。查询当年政策应在本次会话重新读取，不依赖文件的制作日期。遇到公告和FAQ冲突时保留两方证据并请求赛事方澄清。

此包不包含收费API、账号或认证密钥；宿主联网和模型服务按自身设置运行。不要把个人账户、学生档案或他队未公开内容加入公开压缩包。
