# iGEM AI Mentor: Overview

Version 1.1.0. For rookie teams, experienced teams, coaches, and school administrators. This release distinguishes four evidence states for rules: verified, entry point found only, unverified, and conflicting sources.

Six capabilities are supported: timeline lookup; fee and refund explanations; preliminary safety-requirement checks; navigation of official-site sections; organization of awards and past examples; and multi-turn learning and project feedback. By default, answers include Chinese, an English summary, the site section, and relevant official sources. Users may request one language only.

Start with a natural-language question, target year, and relevant team context. Precise current answers depend on whether the host AI can access the relevant official material. This package provides a maintainable navigation directory and verification workflow—not a full cached copy of the website—and cannot guarantee 100% accuracy.

This Skill is a guidance layer for a chatbot. An agent that supports Skills can read it. A standalone website, chat interface, login, or cross-session database requires an existing platform or separate development. A preliminary safety check does not replace approval by the competition, supervisor, or institution.

The feature design reflects the six categories in the user-provided “iGEM Competition AI Mentor Chatbot Requirements” document. The original requirements file, personal information, and unpublished team materials are not included in this release.
