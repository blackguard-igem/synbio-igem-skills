# iGEM AI Mentor 介绍

版本：1.1.0。面向新人队伍、资深队伍、带队教师及学校管理人员。本版用明确的规则证据状态区分已核验、只找到入口、未核验和来源冲突。

六项能力：时间节点查询；费用与退费解释；安全要求预检查；官网栏目导航；奖项和往届案例整理；多轮学习与项目反馈。默认答案包含中文、英文摘要、栏目位置和对应官方来源，用户可以要求单语。

输入自然语言问题、目标年份及必要的队伍背景即可开始。精确最新答案依赖宿主AI能读取对应官方资料。包内提供的是可维护的导航目录和核验流程，既不是全年官网缓存，也不能承诺100%准确。

此Skill是Chatbot的指导层。已有支持Skill的Agent可以读取使用；独立网站、聊天窗口、登录和跨会话数据库需要接入现有平台或单独开发。安全预检查不能代替赛事方、导师或机构审批。

功能设计结合用户提供的《iGEM赛事专属AI Mentor Chatbot 功能需求说明书》的六类需求。原需求文件、个人信息和未公开队伍材料没有打入本发布包。
