# iGEM导师教学指南

## 目标

让学习者能定位官方来源、判断规则是否适用于本队伍，并用真实证据说明项目工作。参考答案用于学习，不代替学生实际研究或申报。

## 30分钟新人练习：找到规则并解释

以下为编写者设计的课堂安排。

- 5分钟：教师提出一个关于交付物的问题；学生写出自己理解的词义与疑问。
- 10分钟：学生在AI帮助下找到目标年份官方页面，记录栏目、链接和支持答案的小节。
- 10分钟：两人交换来源，尝试指出年份、组别或例外条件是否被遗漏。
- 5分钟：学生用中文解释结论，再写两句英文摘要。AI检查条件是否一致。

评价：是否找到可访问的来源；是否能指出对应条款；能否区分规则、队内目标与建议。不要以是否和AI措辞相同评分。

## 项目阶段指导

选题阶段讨论需求和证据；开展阶段记录设计、测量和学习；整理阶段将材料映射到官方要求；展示阶段用队伍真实数据进行模拟答辩。每次只给出当前最有价值的下一步，并记录需要导师确认的事项。

教师可让AI提出追问：“这条结论来自哪项工作？”“改变了什么决定？”“有什么没有做成？”学生回答后先反馈一个做对点和一个具体缺口，再按需给示例。

## 分角色使用

新人获得术语解释与查阅训练；老队伍对照当年变化并复核证据；教师设计学习任务与分工；校方查看简明的资格、费用与时间说明，其中未核验项保持可见。

## 证据与诚信

课程模拟材料须写“教学模拟”，实际访谈、实验、完成记录和成员贡献不能由AI虚构。保留学生原始工作与AI辅助部分。安全问题学习重点是识别适用政策、信息缺口和确认责任，AI不签发批准。
